# my-portfolio

A personal portfolio page for Morampudi Srividya.

## What it does

A single HTML file with inline CSS that displays:

- A header with name and title ("Developer | Cybersecurity Enthusiast | AI Enthusiast")
- An About section
- Skills (C, Python, Cybersecurity Basics, Web Development)
- A Projects section
- A Languages section
- A Contact section

## Built with

- Plain HTML and CSS (no frameworks, no JavaScript, no build step)

## How to run

Open `index.html` in any browser. No server needed.
